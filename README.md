# citibike-ridership
# Citi Bike Ridership Prediction

This project analyzes New York Citi Bike ridership by combining daily trip data with historical weather observations using Google BigQuery. The resulting dataset will be used to build a predictive model of daily bike demand.

## Repository Structure

code/
Contains notebooks for exploratory analysis, preprocessing, and modeling.

data/
Contains the exported CSV dataset generated from BigQuery.

queries/
Contains SQL scripts used to build the dataset.

docs/
Contains project notes and supporting documentation.
